# 参考资料

本目录保存端点状态概览、抓包和协议样本，用于实现与调查时追溯证据。参考资料可能不完整、来自较早版本或尚未与当前代码重新核对，因此不能单独作为“功能已完成”的依据。

- [端点实现状态](./routes-status.md)：按端点记录 Complete、Partial 或 Incomplete。
- [路由抓包索引](routes/README.md)：原始请求、响应和字段样本。

开发新端点时应依次检查：CN 1.8.1 客户端反编译代码、当前路由实现、相关系统或协议文档、实际请求样本。实现完成后同步更新状态表；通用语义应写入 current 文档，不堆叠到抓包正文中。
