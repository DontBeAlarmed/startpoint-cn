## #1 池关闭转换发错币种（P1）【必现】

- 前置：无——CN 1.4.54 所有卡池在服务器时间（2024-08-14）前已过期，
  转换检查在每次 /load 机会性触发。
- 步骤：
  1. 在任一带兑换点的卡池（特选/Pickup 类）用星导石抽 10 连×1
  2. 回主城（触发 /load）
  3. 检查三处：星之粒（物品 990008）背包数量 / 星之碎片兑换所余额 /
     是否出现「已转换为星之粒」GetItem toast
- 官方预期：星之粒 +兑换点数，有 toast 与弹窗
- 当前表现：星之粒=0；星之碎片余额 +兑换点数；无 toast（转换静默记账）

## #2 救援响应免体力（P1）【双设备】

- 前置：设备 A/B，B 与 A 非互关
- 步骤：
  1. A 建领主战（协力 boss）房间并开铃铛招募
  2. B 从铃铛列表响应加入（确认未关注 A）
  3. 记录 B 战前体力值
  4. 通关一场
  5. 对比 B 的实际体力扣减与客户端结算显示
- 官方预期：B 扣 0（客户端显示 0，服务端也应 0）
- 当前表现：客户端显示 0，服务端按非互关折半扣 1/2——B 体力实际减少
- 对照组：B↔A 互关后再测一轮，应为 0/0 ✓

## #3 星之碎片 75:1 链缺失（P2）【admin 辅助】

- 前置：admin 给测试号发放**付费**星导石（vmoney paid 侧）
- 步骤：
  1. 用付费石抽 10 连×若干（累计消耗跨 75 付费石）
  2. 查抽卡日志有无「获得了星之碎片×N」
  3. 查邮件有无碎片领取邮件
  4. 查星之碎片兑换所余额（= user_info.star_crumb）是否变动
- 官方预期：跨 75 触发碎片邮件；日志行出现；余额增加
- 当前表现：三者全无（余额唯一进账是 #1 的错误转换）
- 附测：1天1次限定付费扭蛋的 +2/+1 固定碎片同缺

## #4 中断战斗 90 天删除（P2）【DB 验证】

- 真机不可测（90 天）。验证法：
  1. 真机制造一个中断局（战斗中杀进程）
  2. DB 查 `players_active_quests` 行存在且无过期/时间字段
  3. 任意天数后登录确认仍恢复（无清理任务）
- 修复后验收：admin 改 lastLoginTime 到 91 天前 → 登录 → 该局被删、
  不返还、直接进主城

## #5 领主币碎片范围（P2）【双设备】

- 步骤：
  1. A 建领主战房间（可不开铃铛）
  2. B 直接输房号加入（非铃铛响应）
  3. 通关
  4. 查 B 的领主战碎片/货币收入
- 官方预期：B（非救援响应者）不获得救援碎片
- 当前表现：B 获得（后台开关 `multi_rescue_fragment_rewards_enabled`
  可关做对照）

## #6 关注奖励语义（P2）【双设备】

- 步骤：
  1. A 单向关注 B（B 未回关）
  2. A+B 打一场共斗，看结算 FinalScore 明细中 follow_bonus 值
  3. 另测：A↔B 互关打一场（+10）→ B 取关 A → 再打一场 → 看 A 的
     follow_bonus 值
- 官方预期：单向=0；取关后保留冻结值
- 当前表现：单向=+10/局；取关后清零重计
