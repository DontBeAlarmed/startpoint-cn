# 实现与验收状态

本目录只维护当前状态，不复制架构细节，也不保存历史变更流水。历史由 Git 提交记录承担。

- [项目支持矩阵](./support-matrix.md)：逐模块区分服务端实现、自动测试、CN 客户端或宿主验收和权威文档。
- [当前已知问题](./known-issues.md)：尚未解决、明确受限或等待复核的问题。
- [人工验收矩阵](./test-progress.md)：客户端、浏览器和宿主的已测、待测及低优先级流程。
- [路由族覆盖矩阵](../reference/routes-status.md)：按业务路由族记录 Complete、Partial、Stub 和 Missing。

自动测试通过只说明被覆盖的服务端行为没有回归，不等于官方客户端或真实宿主已经验收。状态变化时应更新本目录，并把稳定行为写入对应 current 文档。
