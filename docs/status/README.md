# 实现与验收状态

本目录只记录当前完成度、未解决问题和客户端验收结果，不重复维护架构或协议字段。

- [测试进度](./test-progress.md)：客户端已测、待测和降低优先级的流程。
- [已知问题](./known-issues.md)：当前仍需处理的问题及影响。
- [变更记录](./changelog.md)：历史开发记录，后续将继续提炼和归档。
- [端点实现状态](../reference/routes-status.md)：端点级覆盖概览。

自动测试通过只说明受覆盖的服务端行为没有回归，不等于官方客户端流程已经验收。状态结论应注明证据来源，并在修复或验证后及时移除过期描述。
