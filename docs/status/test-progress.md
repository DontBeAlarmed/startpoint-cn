# 全项目人工验收矩阵

本文只记录人工流程验收，不记录 C3212、C2274 等历史排查时间线。服务端自动测试覆盖见[支持矩阵](./support-matrix.md)；某项“已实现”但未列入“已通过”，就不能对外宣称已经通过官方 CN 客户端验证。

状态定义：

- **已通过**：当前 dev 代码对应流程已有明确客户端结果；
- **待测**：服务端实现存在，但当前版本仍需客户端复核；
- **低优先级**：缺少测试条件或不阻塞主要单机流程；
- **未实现**：没有可验收的完整流程；
- **非客户端验收**：应由浏览器、Android/桌面宿主或部署环境验证。
