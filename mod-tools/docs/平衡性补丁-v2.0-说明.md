## 相对 v1 的设计修正（按反馈）

v1 是"一个属性一个方向"；v2 改为**按每个角色自身词条判定流派**——每个属性内部
技能伤害/强化弹射/fever/协力球(直击)/能力伤害各流派都有代表，强化顺着角色本来的玩法走。

## 一、流派专精行（473 行，替换 v1）

**判定方法**：扫描角色 6 个词条槽＋队长技的效果枚举（技能伤害系/弹射系/fever系/
能力伤害系[含 EnemyDamage 系直伤词条]/直击系）计分，主动技为召唤物（multi_ball）
的计入协力球/直击流派；平手用属性倾向破，零信号才落属性默认。

**实测分布**（473 人）：技能伤害 231 · 强化弹射 115 · 直击(协力球) 77 · Fever 41 · 能力伤害 9

**判定抽查**：瓦格纳→弹射 ✓ 玛丽娜(海盗船召唤)→协力球/直击 ✓ 两个罗尔夫→弹射 ✓
玛格诺斯→技能 ✓ 光莉莉丝→能力伤害 ✓

**数值分层**（同 v1；Fever 流派因条件生效 ×2；点名角色 +8pp）：
五星初代 15% / 中期 12% / 近代 10% / 基线组 8% / 四星 12% / 三星 15%。
实现仍用官方先例结构（恒真 HpLow≤100% 常驻；Fever 流派= during_trigger 4）。

## 二、三星/四星 → 五星水平

1. **词条数值逐效果对齐**（853 行）：以五星在**同一效果枚举**上的中位数为基准，
   3/4 星低于基准 5% 以上的，把 SLv1/满级值一起拉到基准（封顶 ×2，只升不降）。
   之所以不盲乘：实测 3/4 星与 5 星在同效果上中位差只有 ~1.0-1.05×，差距集中在
   伤害类枚举（1.6-2.5×）——逐效果对齐正好只补短板。
2. **队长技同法对齐**（219 行，基准取五星队长技）。
3. **基础数值**（238 人）：目标提升到基线均值 95%（v1 是 85%/75%），
   涨幅封顶 四星×1.35 / 三星×1.55，只升不降。

## 三、全角色 QoL：解决"冷却长/暖脚久/启动难"（词条 1483 行＋队长技 246 行）

针对光莉莉丝这类"能力伤害弱势、冷却太长、暖脚太久"的通用规则（全角色适用）：

| 项 | 规则 | 例 |
|---|---|---|
| 触发冷却 | ×0.6（≥1） | 瓦格纳词条冷却 10→6 |
| 增益次数上限 | ×2 | 触发上限 1→2 次 |
| 最大累积层数 | ×1.5 向上取整 | 5 层→8 层 |
| 计数型启动阈值 | ×0.7（最低 1 次；只动 ≥2 次的计数阈值） | "5 次弹射后"→4 次，"3 次"→2 次 |

血量型阈值（HP≥X%/≤X%）**不动**——HpLow 类阈值降低反而是削弱，方向不可盲判。

## 五、Boss 血量（从原值重算，不叠加 v1）

  例：zegura 400→1000。
